# Story-page engraving prompts

Mode: built-in `image_gen` generation. Each source PNG is 1122 × 1402 pixels; each WebP copy was made with `cwebp -q 85` and retains those dimensions.

## preface-engraving

Use case: historical-scene. Asset type: portrait editorial illustration for an ARC republic website story page. Primary request: a classical scholar's writing table with an open blank folio, a feather quill, and one small red wax seal; an intimate ancient library doorway receding behind. A letter to an unknown reader. Style/medium: masterful antique copperplate and woodcut editorial engraving, fine near-black ink linework, quiet classical Mediterranean atmosphere. Composition/framing: portrait 4:5 composition; complete scene and generous soft quiet parchment margins on all edges. Lighting/mood: warm contemplative late-afternoon interior. Color palette: warm ivory parchment #f3e7cf with subtle real paper grain, near-black ink, sparse restrained oxblood only in wax seal. Constraints: no readable words, letters, symbols, logos, watermark, neon, UI, modern objects, people, robots, or mascots.

## borrowed-name-engraving

Composition/framing: portrait 4:5; full tag, entire ribbon connection, and whole distant arch within generous calm parchment margins. Lighting/mood: intimate, fragile, literary classical Mediterranean atmosphere. Color palette: near-black ink with sparse oxblood reserved for the fraying ribbon. Constraints: full beautiful scene; no words, letters, numbers, logos, watermark, neon, UI, modern objects, people, robots, or mascots.
