# Lamp smoke animation

Generated with Higgsfield's Kling 3.0 in standard mode, using the original extinguished-lamp engraving as both the first and last reference frames. Exact prompt and job information are retained in `generation.json`.

The generated video softened the architecture. The final `../../extinguished-smoke.mp4` applies only changes relative to the generated first frame within a feathered smoke region to the original artwork. This keeps the original engraving detail and fixed lamp while the pale smoke changes gently. No additional generation was needed for this correction.

Final file: silent, 5 seconds, 1122 by 1402, 24 frames per second. Regional motion measurements are in `inspection.json`. Visual inspection and browser playback confirmed subtle smoke movement. A mathematically seamless repeat is not claimed.
